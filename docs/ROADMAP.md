# Roadmap

- Static JSON data.
- Premium UI shell.
- 3D placeholder viewer.
- Exploded view, interior camera, x-ray and hotspot interactions.
- SEO routes, sitemap, robots and JSON-LD.

## Phase 2

- Licensed real 3D assets.
- Full parts hierarchy and accurate exploded vectors.
- Interior tour collision constraints.
- Low-poly mobile asset variants.

## Phase 3

- CMS-ready data editing.
- Automated official source checker.
- Internal validation dashboard.

## Phase 4

- Personalization and AI-assisted vehicle recommendation.
- Saved comparisons.
- Lead handoff to official source.

## Phase 5

- Analytics dashboard.
- SEO content operations.
- A/B testing for CTA and 3D interaction funnels.
